Check targets: $versions

Each note comes from facts/ and has an executable check. Details attributed to external documentation are not covered by that check. These notes describe the pinned versions; newer releases may behave differently.

A Python UDF is a user-defined function that runs inside a query. The Python UDF section covers how Sail runs these functions and what that means for your code.

The checks workflow tests the pinned versions and runs a weekly check against the latest stable Sail package. A failed check is a reason to investigate the behavior and update the note when appropriate.
