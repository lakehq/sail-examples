FROM CURIOUS TO RUNNING

Your first answer is
a few commands away.

Install uv, then run the taxi example. It handles Python and package setup for you.

After cd sail-examples, run all guide commands from that repository root. The first run downloads about 1.4 MB of trip data and a small zone lookup, plus Python packages.

TERMINAL 
git clone https://github.com/lakehq/sail-examples.git
cd sail-examples
uv run quickstart/query-files-with-sql/main.py
